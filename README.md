# 🔐 Mediroza Web Application Penetration Testing

## 📌 Overview

This project documents my practical experience in **web application penetration testing** using the Mediroza website in an authorized testing environment.

The assessment involved examining the application from an external perspective, analyzing HTTP requests and responses, and testing for potential web application vulnerabilities.

## 🎯 Objectives

* Understand the process of web application penetration testing
* Analyze web application requests and responses
* Identify potential security vulnerabilities
* Perform SQL Injection testing
* Use security tools to support the assessment
* Document findings in a professional penetration-testing report


## 🛠️ Tools Used

| **TOOL**                          | **PURPOSE**                                                                  |
| --------------------------------- | ---------------------------------------------------------------------------- |
| **cURL**                          | Command line tool for sending HTTP requests and reading web server responses |
| **Burp Suite**                    | Web application request analysis and entering SQL Injection payloads         |
| **Browser**                       | Application interaction and verification                                     |
| **Networkwalks Hash Calculator**  | For extracting password hashes from PDF files                                |
| **Networkwalks Password Cracker** | For cracking PDF password hashes using wordlists                             |
| **qpdf**                          | For decrypting password-protected PDF files after cracking                   |
| **exiftool**                      | For reading hidden metadata from PDF files                                   |
| **ChatGPT**                       | For converting raw SQL data into readable tables                             |


## 🔍 What I Did

During the assessment, I:

* Performed initial reconnaissance of the web application.
* Intercepted and analyzed requests using **Burp Suite**.
* Tested application inputs for possible **SQL Injection** vulnerabilities.
* Used comment-based testing techniques.
* Used **cURL** to send HTTP requests and examine responses.
* Analyzed HTTP status codes and application behaviour.
* Documented the testing process and security findings.
